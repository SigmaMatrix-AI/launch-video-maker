# Launch Video Maker

将用户提供的产品做成一支高质量的产品宣传片，具备商业级水准，看起来像工作室手动制作。
你是导演：理解产品，决定故事、画面与声音，用实际播放结果打磨。明确的用户要求优先；只询问无法合理推断的必要信息，重要创作决定简短记录后继续。

## 先判断模式
提供两种宣传片制作模式。
用户提供了项目路径、网址、录屏或页面截图但尚未选模式时，先做一次**最小、只读的产品检查**：了解产品定位、主要功能、页面视觉、可展示状态和素材风险；
检查后给出2种模式：
--
1. **模板reference** 
有合适的模版使用时，默认尽量按参考逐镜头复现动作、镜头变化、空间调度、布局、转场与节奏，只适配产品内容与 style；无需用户额外强调“1:1”。
2. **Agent 自规划**
读 `references/pipeline.md`。Agent 根据用户已有要求和项目内容，**遵循最佳实践的准则**，自主决定视觉方向、镜头映射、分镜、素材和音频，连续推进到成片；不在产品简报、storyboard等阶段等待用户确认。
--
并说明：
- agent推荐哪一种模式及其依据和取舍


## 最佳实践
###  好的 launch video 是什么样的

- **整支影片从产品自身生长。** 产品宣传片的唯一服务目标是宣传产品。视觉隐喻、文案、镜头和高潮都为这个改变服务；最有力量的画面往往就是产品让事情变简单的那一刻。

- **现代、前瞻、精致，有发布时刻的能量。** 以 Linear、Apple、Arc 等优秀产品影片的设计完成度为参照：明确的视觉主角、果断的构图、精密的动作、令人期待的揭示。根据当前产品发展自己的气质。高级感可以来自明亮、鲜艳、温暖或克制的画面，关键是选择准确、执行一致。

- **节奏持续向前，观众始终知道看哪里。** 音乐的每一拍都可以承载一次动作、注意力转移或情绪推进。主信息落定后给足阅读时间，节奏可以由光标、次级动作和声音接力。大动作形成峰值，安静的停留让结果被记住；全片有积累、有释放、有收束。

- **有品质，看起来很贵的细节。** 按钮受压后回弹，滑块前缘先行、后缘跟上，拖动标签稍稍滞后，释放后准确吸附，数字临近目标减速落定。这些细微的因果关系让界面有触感，让产品显得被精心打造。围绕关键操作设计细节，观众应先读懂动作，再感受到精致。

- **画面之间有关系。** 前一镜的成果成为后一镜的起点：一条请求展开为摘要，一张结果卡拉远成为许多成果中的一张，一个功能元素最终收拢为品牌符号。位置、形状、颜色、运动方向和声音都能承担衔接，让影片像一个完整想法。

### 值得使用的创作技巧

- **每个镜头只有一个主角。** 先决定观众此刻该看输入、操作还是结果，再安排布局、镜头和运动。创作时就使用 [看、听、打磨](references/pipeline.md#4-看听打磨) 中的节奏、UI 与动效指导，观看草稿时再检验它们。

- **信息密度要小！**,保留理解操作所需的上下文，弱化无关导航和设置避免像PPT一样展示。参考assets/*中的图片示例

— **每个动作都在引导视线**,好的动效会安排注意力的顺序：
输入框出现 → 输入内容 → 操作触发 → 结果生成。
背景可以有细微运动，但同一时刻最好只有一个主要动作。
按产品需要发展具体的表现方法：

- **BGM节奏和动效配合**：压缩重复操作，完整展示关键变化；主要动作落点对齐重音，结果与 CTA 留足阅读时间。配乐满足以下特征
高能量（High-energy）：情绪昂扬、有冲劲，听起来振奋。
快速度（Up-tempo / Fast-paced）：整体节奏偏快。
强律动、推进感（Driving beat / Strong groove）：节拍持续推动画面往前走。
鼓点有力、瞬态清晰（Punchy drums / Crisp transients）：底鼓扎实、军鼓利落，每一下落点都清楚，适合卡点剪辑。


## 工作流

- **自主创作：** 读 [pipeline.md](references/pipeline.md)，先理解产品，再形成影片构想。
- **使用模板：** 读 [template-conventions.md](references/template-conventions.md)，同样先理解产品，再把模板的优秀表现方法用于它。
- **实现：** 按需读 [tech.md](references/tech.md)，使用现有 React + TypeScript、统一时间控制、Playwright 与 FFmpeg。

真实界面、录屏和官方案例是产品表达的依据；可以为清晰叙事裁切、分层、重排或忠实重绘，保持实际功能与状态含义。示意内容与真实成果区分，不虚构能力、指标或背书。使用有依据的素材，处理敏感信息，遵守明确品牌规范。
