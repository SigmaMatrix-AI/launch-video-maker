# Launch Video Maker 开发计划

已确认：自主决策；仅按请求展示预览和导出；React/TypeScript + 统一帧控制 + Playwright/FFmpeg；macOS 优先。模板和正式 styles 保持空目录。Style 通常只有自由格式 style.md；demo 是可选应用参考，无须独立运行，不移植其完整引擎。Brand kit 在影片工程内。

## Task 1: 独立工程与帧运行核心
单一可打包 runtime，doctor/init/setup；工程携带 vendor runtime tgz、lockfile。defineFilm、有理帧率、半开场景区间、确定性随机和插值；帧请求携带版本和 id，资源就绪握手。测试边界、随机取帧、错误资源和可移植安装。

## Task 2: Player 与媒体
播放、暂停、拖动、逐帧、音频试听，无编辑器。React 提交、字体、图片、异步任务明确就绪。FFmpeg 预解码，VFR 按归一化 PTS 覆盖区间映射，显式越界策略。缓存按输入内容/参数，取消过期请求，缓冲时音画一起暂停。不默认打开浏览器。

## Task 3: 共享音频
裁切、增益包络、淡入淡出、显式循环与不足策略，场景/动作相对锚点。统一 48k stereo PCM 预混，预览与编码共用；速度重采样变调。检测削波，避免隐式 amix 归一化。验证 seek、版本失效、混合采样率、尾部与长时同步。

## Task 4: 渲染与检查
prepare/preview/still/render/inspect；串行 set-ready-validate-screenshot 事务锁定版本。恰好 N 帧，H264/yuv420p/AAC MP4 默认 1080p30，可配置。显式 render 才导出；失败清理，不覆盖旧结果。检查实际成片帧数/音频/规格，探针同步误差不超过一帧。

## Task 5: 制作工具与审查
capture 提供高分辨率页面、元素、坐标与来源，可扩展工程交互脚本。analyze-audio 提供波形/峰值/瞬态候选/能量，Agent 试听校准。review-pack 收集简报、品牌、方向、分镜、版本、静帧、混音、技术证据。独立 subagent 实看动态、试听，七维各 ≥7.5 且无阻断/证据缺失才通过。

## Task 6: 风格/产品验收与文档
依据两份初始 style 各制作新的 10–15 秒验证片，不复刻 demo 叙事。独立产品实战需要真实产品资料，缺失时标明未完成。迁移工程并清空依赖/隔离浏览器缓存重装。README 写工具现状，SKILL 保持长期行为规则。

## 验证分层与借鉴
技术 fixture 不打商用审美分；风格验证片验证方向；真实产品全片才做完整七维商业验收。验证首尾/交界/随机倒序、24/30/60/分数 fps、横竖屏、失败资源、VFR/非零 PTS、音频包络/循环/seek、60 秒同步、独立安装、无自动浏览器/MP4。

借鉴 video-shotcraft 的产品证据、品牌依据、styleframe/短动态验证、高清真实界面与布局采集、动作起承转合、节奏前置和具体证据审查。允许忠实 UI 重绘，禁止虚构功能。不修改或依赖原工程文件。

## 执行与交付
按任务记录 RED→GREEN 和阶段提交，保留用户未跟踪样例。最后独立代码审查。不得将源码完成、技术测试通过和商业审查通过混为一谈。默认不发布、不推送、不提交生成缓存或 MP4。
