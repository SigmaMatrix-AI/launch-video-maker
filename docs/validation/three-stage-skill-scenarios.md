# Three-Stage Skill Behavioral Validation

Give the same inputs to fresh-context agents that read only the old snapshot or the new worktree, respectively. Output only the concrete next action, deliverable format, and a short user response; do not produce films. Each scenario is independent, and all products, confirmations, and time pressures are simulated. Never enter these approvals into real film records.

## Fixed Materials

Test product Feedback Flow (a fictional test product): collect customer feedback in a list; the user selects entries, merges similar items, and adjusts priority to produce a sorted list. Existing test assets include the feedback list, selection state, and priority results page; the interface has a header, navigation, list title, and status labels. The target audience is product managers; the video is approximately 25 seconds. The brand is neutral and colors may be freely chosen. Do not claim automatic AI analysis, customer endorsements, or a percentage of time saved. Assume complete assets in the test; no web research is needed.

## Scoring and Evidence Scope

Manually read complete responses and record actual choices and quotations. pass = explicitly covers the expectation; partial = no violation but missing a key action; fail = explicit conflict. Never report an unobserved failure as reproduced. One passing short response establishes only that this decision followed the agreement, not reliable behavior across turns or improved finished films.

If stage boundaries are ambiguous, run at least five independent microtests each for old/new versions on the ambiguous inputs. Without ambiguity, do not add repeated renders. Produce the visual comparison separately; neither this file nor text-string tests replace observing actual output.
