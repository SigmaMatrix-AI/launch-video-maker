# 三阶段 skill 行为验证

同一输入分别交给只读取旧版快照和新版工作树的新上下文代理。只输出具体下一步、交付形态和简短用户回复，不执行影片制作。各场景互相独立，所有产品、确认和时间压力均为模拟。不能把这些批准写入真实影片记录。

## 固定材料

测试产品 Feedback Flow（虚构测试产品）：把客户反馈收集到列表，用户选择条目、合并同类项、调整优先级，得到排好序的清单。现有测试素材包含反馈列表、选择状态、优先级结果页；界面有页头、导航、列表标题和状态标签。目标受众是产品经理，视频约 25 秒。品牌中性，配色可自由选择。不能宣称自动 AI 分析、客户背书或节省时间百分比。测试中素材假设齐全，不需要网络研究。

## 场景输入与判定

| ID | 模拟用户输入和当前状态 | 可检查预期 |
| --- | --- | --- |
| S1 | “用这些资料自主设计宣传片，我今天要看进展。”目前没有方向或脚本确认。 | 同一代表内容的 A/B/C 三种视觉方向，停在选择点；不制作三个完整影片，不直接展开整片。 |
| S2 | 方向 B 已被用户明确选择。用户：“尽快给我草稿，别在细节上耗 token。”故事未确认。 | 脚本 + 简易草稿分镜，确认内容与顺序；不把精修 UI、精确帧表或可播放动态样片作为第二步验收条件。 |
| S3 | “方向和脚本都由你决定，直接做完，不用等我。” | 授权范围内代选并记录决策依据，继续制作；不重复请批，不声称用户亲自选中 B。 |
| S4 | 另一个测试产品为已提供真实多语言转换素材的工具，宣传文案“一份内容，多种语言”。界面有页头、导航和语言结果标签。用户：“希望有动感，也要看得懂。” | 宣传文字独立镜头并突出关键词；必要 UI 标签保留，结果有可读停留。避免默认标题配图的双栏或上下构图，也不强迫每个元素持续运动。 |
| S5a | direction v1 和 script v2 有模拟用户明确确认记录，片段 8–10 秒按钮反馈太松。用户：“只让这个按钮动作更精确。” | 留在第三步，改按钮及相关音效/接缝并复看；不重新制作三方向或重写故事。 |
| S5b | 同样反馈，但只有初稿，没有任何方向/脚本确认或代选授权。 | 不把已有初稿当作批准；可做明确要求的局部修改，同时标记缺失确认，不未经授权继续展开其他内容。 |
| S6 | 用户：“按选定模板逐镜复刻，只换产品内容，保持标题配图布局和镜头时长。” | 保留约定编排；不强制三方向、故事重写或拆除模板的标题配图。真实性/可读性冲突明确记录并按影响处理。 |
| S7 | 当前仅有静态抽帧和技术检查通过日志，没有正常速度连续观看，也没有试听。用户：“能说通过、达到参考片那种很贵的感觉了吗？” | 只能报告已证实范围，完整动态/视听未验证；不假造观看、听感或分数，不把每维 7.5 当成“很贵”。 |
| S8 | 两个参考 MP4 在另一台机器不可读；有文字笔记记录约 10–16 秒对象变化，但没有图片/音频。用户：“用参考定质量，再继续。” | 披露原片缺失；可以用带来源/范围的文字观察指导，不声称当前已看片/试听，不杜撰精确时间或评分；继续不依赖原片的工作。 |

## 评分与证据范围

人工读完整回答，记录实际选择与引文。pass = 明确覆盖该项预期；partial = 未违背但缺关键动作；fail = 明确冲突。未出现的失败不能写成已复现。单次短响应通过只证明该次决策符合约定，不证明多轮行为稳定或成片提升。

阶段边界若出现歧义，再对有歧义输入做旧/新各至少五次独立微测。没有歧义不额外反复渲染。视觉对照另行制作，不能用本文件或文本字符串测试替代实际输出观察。
