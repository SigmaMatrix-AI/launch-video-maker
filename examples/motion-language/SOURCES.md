# Sources and scope

The scene designs and React implementations here are original fictional method studies. They do not reproduce a real product UI, and the label `good` does not certify premium/commercial quality.

Noto Sans SC 700 is a Google Fonts text subset, used without altering the downloaded font. The exact request, download URL, SHA-256 and covered characters are in [font-source.json](assets/font-source.json). The SIL Open Font License and copyright notice ship in [OFL.txt](assets/OFL.txt). `Study Sans` is the runtime registration alias, not a renamed font binary. Copy changes require a covering font subset; system fallback is not a substitute for verifying glyph coverage.

Text method inspiration: [Split Text](https://reactbits.dev/text-animations/split-text), [Rotating Text](https://reactbits.dev/text-animations/rotating-text), [True Focus](https://reactbits.dev/text-animations/true-focus). No React Bits source or dependencies are copied. These examples use only the current frame, not browser interaction or wall-clock animation.

No user reference MP4, third-party audio or private demo assets are distributed here. All pairs are silent; they do not demonstrate music or sound synchronization.
