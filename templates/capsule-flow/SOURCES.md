# Sources and reuse boundaries

The bundled TapVid example originated in a user-directed project adapted from a Google Vids reference. Changes include cube type rotation, green gradients, plane transitions, URL composer morph, shorter gallery, removed waveform/countdown, and a frosted logo button. This is an adapted template, not a claim of entirely independent original choreography.

Official TapVid logo and example media: https://tapvid.ai. Exact URLs and capture details are retained in [asset sources](assets/sources.md), [downloads](assets/research/downloads.json), and [brand sources](brand-kit/sources.md). Replace these for other products. The composer is an illustrative reconstruction; the presenter result is an official example, not proof of an actual generated product-launch result.

The included capsule-flow-bgm-edit.wav is a timing/EQ/gain edit of user-selected reference music with its spoken interval patched out. See [audio edit provenance](records/audio-edit.json) and [final BGM recipe](records/bgm-rework.json). The intermediate source WAV is not distributed; its hash and recipe are retained, and the file remains in Git history. Licensing for unrelated/public projects is unverified; replace with appropriately licensed music when reusing. Google Sans retains reference provenance; no new license grant is asserted. No voiceover was added.

The [package snapshot](records/snapshot.json) records retained files. Old exports, inspection PNGs, and production iteration logs are not required to run the template. Historical technical reviews are not acceptance evidence for a newly adapted film.
