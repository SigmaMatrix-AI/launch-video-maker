# Sources and reuse boundaries

The TapVid demo uses a motion sequence adapted from a Google Vids reference, with rotating cube typography, green gradients, plane transitions, a URL composer morph, a gallery, and a frosted logo button.

Official TapVid logo and example media: https://tapvid.ai. Exact URLs and capture details are retained in [asset sources](assets/sources.md), [downloads](assets/research/downloads.json), and [brand sources](brand-kit/sources.md). Replace these for other products. The composer is an illustrative reconstruction; the presenter result is an official example, not proof of an actual generated product-launch result.

The included capsule-flow-bgm-edit.wav is an edited reference track with timing, EQ, and gain adjustments and its spoken interval patched out. See [audio edit provenance](records/audio-edit.json) and [final BGM recipe](records/bgm-rework.json). The intermediate source WAV is not distributed in the current tree; its hash and recipe are retained, and the file remains in Git history. Public use and redistribution permission for this music are unverified; obtain suitable permission or replace it. No voiceover was added.

The bundled Google Sans version 13.002 has OFL metadata and an official upstream OFL notice; retain [GoogleSans-OFL.txt](brand-kit/GoogleSans-OFL.txt) with the font. This font license does not cover the TapVid media, logo, or music; their source records do not supply a general redistribution grant. The cursor artwork is maintainer-owned and requires no third-party permission.

The [package snapshot](records/snapshot.json) records retained files. Old exports, inspection PNGs, and production iteration logs are not required to run the template. Historical technical reviews are not acceptance evidence for a newly adapted film.
