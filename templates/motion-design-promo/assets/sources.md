# Sources and usage boundaries

This package was migrated from the user-provided local React project `motion-design-promo-01`. Source-relative paths and SHA-256 hashes are in `records/source-manifest.json` for provenance only; they do not participate in execution, and the source project need not exist.

- Motion: the source project's six template/boards JSX files and design.js; retains fourteen actions and the 20-second sequence. Only font wiring changed; this does not claim ownership of all rights to the original reference film.
- Example: the current six-image version of source props/shiqu-shopping; SHIQU is fictional. media-plan.json records product and other assets as generated by built-in image_gen; existing files are retained without regeneration. Example images, people, and fictional pages cannot serve as target-product facts or customer testimonials. Replace them for new films.
- Audio: existing music-master.wav, 48kHz stereo, 20 seconds. Source scripts derived it by trimming/processing original-music.wav. Existing source materials lack a complete music license sufficient to confirm public redistribution rights; this package adds no licensing claims. Before publicly releasing the template or a film, use appropriately licensed music or supply source documentation.
- Fonts: Inter 400/800 and Noto Sans SC Chinese fallback A/B/C 400/800; the source project's report.md labels them OFL. Migration retains original files; the source directory did not include separate OFL text, so this description is not elevated to new license evidence.
- Runtime: standalone @launch-video-maker/runtime 0.1.0 snapshot; dependency versions are pinned by package-lock. The repository specifies no overall license; MIT cannot be inferred.

This migration is for the user's local use. Before distribution in a public repository, supply required third-party license texts and asset/music provenance evidence.
