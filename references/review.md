# 审查与修复

目标是**高端商用定制标准**：信息清楚、品牌可信、视觉方向一致、有产品针对性的创意、精细动效与声音工艺，以及可靠的技术输出。仅能播放、没有报错或平均分较高都不足以通过。

使用 Player 检查动态与共享混音；用户触发导出后再检查实际 MP4。文档审阅、源码检查与静帧检查只证明其各自覆盖的内容，不能代替动态、声音或实际成片检查。

## 两种验收对象

| 对象 | 何时进行 | 能证明什么 | 不能证明什么 |
| --- | --- | --- | --- |
| 预览工程 | 内部自检后、交付可预览工程前 | 当前版本在共享 runtime 中的画面、动态、音频与交互定位表现 | MP4 编码画质、封装规格、编码后的音频与同步 |
| 导出成片 | 用户要求导出后 | 实际 MP4 的画质、规格、完整性、声音与同步 | 未来修改版本仍然合格 |

默认流程完成预览工程验收，不自动导出。不能为获得成片评测输入越过用户触发导出的条件。预览工程可使用后台 Player、关键帧、播放记录和音频检查证据进行内部审查，无需自动向用户打开浏览器。

## 独立 subagent 评测

制作 Agent 先完成逐场景与全片自检，再将当前影片交给**未参与制作、使用干净上下文的独立 subagent**。制作 Agent 的自评分不能代替独立审查。

提供评测所需事实和可观察产物：

- 用户要求、产品简报、核心卖点依据、技术规格。
- 视觉方向、用户参考、选用的模板/style 及实际借鉴范围；没有内置参考时提供自主设计的方向记录。
- brand kit 的素材、明确规范、推断、来源及替代记录。
- 当前分镜、场景帧区间、共享音频时间线、当前内容版本。
- 可访问的完整视听预览、关键帧、必要的源文件及技术检查证据；成片评测另提供实际 MP4。

不得提供“应该通过”的结论、要求凑分或用制作过程的辩解引导判断。评测者须实际观察动态并听取音频；无访问、播放或听音能力时，标记相关项“无法验证”，不能仅根据源码或波形猜测审美得分。

没有独立 subagent 能力时记录“独立评测未完成”，交付状态保持待审查，不声称达标。

## 七维评分与证据

各项使用 0–10 分，可保留一位小数。**七项全部不低于 7.5 才满足分数条件；不使用平均分、加权抵消或四舍五入把低分提升到门槛。** 必要证据不足的维度记“无法验证”，不填默认分数、不跳过放行。

| 维度 | 重点检查与达标依据 |
| --- | --- |
| 风格还原 | 对照记录的风格方向、用户参考和品牌规范；字体、配色、布局、动效性格与材质一致。无内置 style 时仍按本片方向评估；不要求模板像素级复刻。 |
| 创意与惊艳 | 表达围绕产品特点，有清晰记忆点与恰当的叙事变化；不是无关炫技或通用效果堆砌。 |
| 动效工艺 | 动作起承转合、缓动、速度、停留、层级及转场连续；没有跳变、闪烁、突兀截断、抖动或无意义重复。 |
| 设计与排版 | 信息层级、栅格、对齐、留白、字体和对比度精细；目标画幅与实际观看尺寸下文字可读，停留时间足够。 |
| 质感与细节 | Logo、截图、纹理、遮罩、边缘、光影及放大清晰度可靠；没有占位、缺图、字体回退、粗糙裁切或不一致的小细节。 |
| 声音与同步 | BGM 符合调性，SFX 与动作有关系；音量层次、裁切、淡入淡出、节拍、起止和尾音自然，无削波、明显偏移或漂移。 |
| 技术规格 | 尺寸、画幅、fps、总帧数、资源加载与确定性满足约定。预览检查播放/暂停/seek/逐帧；成片另检查编码、音频规格、封装和实际画质。 |

评分尺度：低于 7.5 表示仍有影响交付的明显不足；7.5–8.4 表示该维度达到高端商用定制的基本要求；8.5–9.4 表示执行突出且一致；9.5–10 仅用于有充分证据支持的卓越表现。每项解释得分依据及剩余缺点，不能把标准降为“运行正常”。

## 预览工程检查

逐场景检查首帧、关键动作、文字落定、退出和每个交界的前后帧，并连续观看全片、试听完整混音。结合 [运行契约](runtime-contract.md) 检查跳转、倒退、逐帧与连续播放一致性。

重点复核：产品宣称是否有依据，核心卖点是否清楚；brand kit 是否实际被使用；style 是否被落实；文字是否可读；动画和转场是否连续；素材是否完整；声音是否可听且同步。涉及品牌明确规范的偏离须可解释并符合用户要求，不能由模板默认值悄悄覆盖。

硬性阻断包括：错误或误导的产品信息、违反明确用户/品牌要求、敏感信息意外曝光、关键素材缺失或使用依据未解决、关键文字不可读、无法播放/听音、明显音画错位及不符合约定技术规格。分数达到门槛仍有阻断项时，不通过。

## 导出成片检查

对**实际输出的 MP4**重新观察与测量，不以预览结果或渲染进程成功代替：

- 核对尺寸、画幅、fps、总帧数/时长、编码与像素/色彩设置，以及音频采样率、声道和音轨存在性。
- 完整播放成片，在关键场景和转场抽帧对照预览，检查压缩损失、色偏、锯齿、文字模糊、黑帧、缺帧和尾帧截断。
- 试听实际混音，检查声部缺失、增益变化、削波、音频起止及淡出，不能只听原始音源。
- 选取开头、中间、结尾的动作/声音锚点，记录期望与实际位置、误差和测量单位，检查固定偏移和累计漂移。对卡点片额外复核重要拍点；误差容限按制作规格预先记录，不能在发现问题后临时放宽。
- 将实际成片作为七维评测对象，记录新的独立评测结论。既有创意依据可复用，但实际产物的画质、动态、声音和技术证据必须更新。

## 报告与返工闭环

报告至少包含：审查对象（工程或 MP4）、内容版本/文件标识、日期、输入和工具能力、七维得分及证据、阻断项、建议项、无法验证项、最终结论。

每条问题标出维度、场景、全局帧号/时间码、证据位置、可观察现象和修复目标。声音问题附音频区间及试听/测量依据；不要只写“再高级一点”。

结论只使用与证据相符的状态：通过、未通过、评测未完成。通过需同时满足七项 ≥ 7.5、没有阻断项、必要检查全部可验证。

制作 Agent 根据问题修复并更新版本；时序变化同步更新声音时间线和分镜；品牌素材变化更新 brand kit 的来源与引用。独立 subagent 复测改动和关联影响，全片回看确认没有回归后再给结论。若连续修复不能解决问题，记录剩余缺口和需要的输入或能力，不降低阈值、不无限盲改。

回到 [制作流程](pipeline.md) 继续后续交付，按 [SKILL.md](../SKILL.md) 区分预览请求与导出请求。

## 工具辅助

使用 `review-pack .lvm/review` 生成关键帧、混音、版本与制作记录，不自动填分或输出 MP4。独立评测后运行 review-check；该命令校验报告格式和门槛，不能认证评测者确实看过或听过。缺少听音或完整动态观察能力时标记评测未完成。见 [运行指南](runtime-usage.md)。
