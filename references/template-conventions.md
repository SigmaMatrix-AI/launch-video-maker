# 参考模板约定

参考模板是可运行的 React 动画源码，帮助 Agent 理解叙事、布局、动画与节奏实现，不是只能替换素材的硬模板。

内置参考见各包的 `template.md`，例如 [Google Vids](../templates/google-vids/template.md)。模板源码与素材进入版本管理；安装依赖和运行缓存不提交。生成的用户影片保存到仓库 `films/<project-id>/`，不回写模板。

## 发现与组织

后续每个模板放在 `templates/<template-id>/`，入口说明使用 `template.md`。Agent 先读取候选说明判断适配性，再阅读选中模板涉及的源码、素材说明和运行约束，不仅凭目录名称做决定。

一个模板包应包含：

- `template.md`：制作指南，包含适用产品、片子结构、逐段动作与素材要求、换产品指南、源码修改入口和验证方式；不能仅写运行命令或组件文件清单。
- React + TypeScript 场景源码及必要的局部组件、素材。
- 可复现运行所需的依赖声明、锁文件、启动说明与配置；由实际实现提供可用命令，不写不存在的命令。
- 来源及必要的使用/署名说明；附带的品牌元素、示例文案和素材应明确哪些必须替换。

“可运行”指依照说明能装载场景、指定帧并检验动态表现；仅有截图或说明不算可运行模板。模板可通过统一 runtime 运行，但必须声明兼容契约及验证版本。必须完成独立安装、指定帧、完整动态与声音验证，才能宣称已通过运行验收。

## template.md 的制作信息

读完说明，Agent 应在打开源码前知道片子如何展开、要先采集哪些素材、哪些段落适合目标产品。至少讲清以下信息，章节组织可按模板特点调整：

- **片子结构**：规格、叙事与能量变化，时间/帧区间、内容、镜头动作、空间调度、转场承接及源码入口。区分原片观察与当前复刻边界，不能把代码近似当作原片事实。
- **素材清单**：每段需要什么，数量、格式、最大出镜尺寸与清晰度要求；哪些来自真实页面/案例，哪些由代码实现，哪些参考素材必须替换。素材需求要能直接指导产品理解阶段的首批采集。
- **换产品指南**：如何将真实功能映射到段落，如何增删不适用功能，替换文案/截图/Logo/案例的具体位置；同步调整布局、点击目标、相机、时间锚点和声音。说明实际编辑接口，不能编造不存在的统一配置。
- **颜色与视觉职责**：分别说明舞台、控件、内容、状态、渐变与转场的作用及改造边界；给出原片中的具体例子，不能用“替换主题色”概括全部设计。
- **质量与限制**：保留什么动作关系、在哪里容易失真、如何检查；附来源与已知近似。参考静帧可帮助读片，但不代替连续动态检查。

## 自由改造

允许根据产品内容增删场景、重排结构、调整文案和时长，也允许选择模板中的部分连续段落。对选中的参考段落，应尽力保留动作、镜头变化、空间调度、布局与转场节奏；自由改造不等于仅借用几个工具函数，再另造一套通用构图。用户要求贴近原片时，原视频是判断依据，模板源码中的近似实现也需要核对。

在分镜记录参考时间段→本片时间段、对象起止位置、镜头推拉/平移、构图比例、转场路径和必要偏离原因。保留产品真实性，替换原品牌、文案和不适用功能；按参考的颜色职责融合 style 与品牌依据，字体等表面属性按相同原则适配。真实内容、状态与第三方标志不参与全局染色；参考中的多色渐变和局部高饱和段落也不因品牌色仅作点缀就一律去色。

在影片工程中保存借用或改写后的源码和需要的素材，使用工程内引用。模板升级不能隐式改变已交付影片；保留参考版本或内容标识以便复查。

每个模板无需预先支持所有 style。Agent 阅读 [style.md 的约定](style-conventions.md) 后将视觉方向落实为本片代码，并按 [brand kit](brand-kit.md) 替换品牌依据。不得保留参考模板的产品宣称或品牌标志冒充当前产品。

## 运行边界

- 使用 [runtime-contract.md](runtime-contract.md) 的统一帧、场景局部帧、素材解析和音频时间线语义。
- 动画必须能指定任意帧，结果不能依赖此前播放过哪些帧。
- 不引入 Remotion 或可视化编辑器，也不要求 video-shotcraft 的代码、资产或本地路径。
- 所有必要资源必须能从声明的依赖及模板包获得；缺少字体、图片或视频时显式报告，不能静默降级后声称还原通过。
- 新模板运行验收应覆盖起止帧、转场交界、乱序取帧、资源就绪，以及存在音频时的视听同步。

## 没有可用模板时

空目录记录“暂无内置参考模板”；有模板但不适用时记录选择依据。两种情况均可依据简报与视觉方向自主设计，不要求用户提供模板，不从其他工程隐式借资源。运行工具缺失是独立的能力缺口，不通过“无模板自主设计”绕过。
